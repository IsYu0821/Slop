## AI-first development

Slop/MNU is an AI-first operating-system experiment.

The maintainer-controlled development process uses generative AI as a
primary implementation tool to explore how far an operating system can be
developed with AI assistance.

External contributors may use any development method. They are not required
to disclose prompts, models, conversation logs, or AI usage.

AI-generated code is not assumed to be correct, original, secure, or
license-compatible. All contributions remain subject to normal provenance,
testing, security, documentation, and code-review requirements.

See `AI_POLICY.md`, `CONTRIBUTING.md`, `DCO`, and `LICENSE` for the complete
project policies.
