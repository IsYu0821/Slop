# AI Policy

Slop/MNU is an AI-first operating-system project.

SLOP means Synthetic Low-quality Operating Platform.
MNU means Maybe Not Unix.

The project's primary development process uses generative AI to explore
how far an operating system can be developed with AI assistance.

External contributors may use any development method, including:

- generative AI;
- coding agents;
- code-completion systems;
- web-based AI services;
- manually written code;
- any combination of the above.

Contributors are not required to disclose:

- whether AI was used;
- which AI system or service was used;
- prompts or conversation logs;
- the proportion of AI-generated code;
- private development notes.

Claims about AI-assisted development apply only to work completed through
the maintainer-controlled development process. External contributions are
not counted as evidence of AI capability unless explicitly documented as
part of a controlled experiment.

AI-generated code receives no exemption from:

- license compatibility checks;
- provenance review;
- security review;
- testing;
- code review;
- documentation requirements.

AI-generated code is not assumed to be correct, original, secure,
copyrightable, or license-compatible.

Contributors must not knowingly submit proprietary, confidential,
unauthorized, or incompatibly licensed material.

The Apache License 2.0 applies to whatever rights each contributor can
legally grant. No claim is made that every AI-generated fragment is
independently eligible for copyright protection.
