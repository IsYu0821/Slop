# AI Policy

Slop/MNU is an AI-first operating-system project.

SLOP means Synthetic Low-quality Operating Platform.
MNU means Maybe Not Unix.

New implementation code submitted to this repository must be substantially
produced with generative AI assistance.

Human contributors are expected to review, test, debug, edit, document,
and reject generated code when necessary.

AI-generated code receives no exemption from:

- license compatibility checks;
- provenance review;
- security review;
- testing;
- code review;
- documentation requirements.

Contributors must not knowingly submit output copied from an incompatible
third-party source.

The Apache License 2.0 applies to whatever rights each contributor can
legally grant. No claim is made that every AI-generated fragment is
independently eligible for copyright protection.
